# Bundled fonts

Caveat and Bangers provide the legacy sketch typography. Their SIL Open Font License notices are stored alongside their TTF files.

Version 2 clean typography uses Noto Sans with its default normal-width, regular-weight variation. The variable TTF and license were obtained from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosans). `NotoSans-Variable.ttf` is the upstream `NotoSans[wdth,wght].ttf` filename renamed for local packaging. See `NotoSans-OFL.txt` for copyright and license terms.

Rendering and text measurement use bundled files. No network font requests occur during preview, capture, or export.
